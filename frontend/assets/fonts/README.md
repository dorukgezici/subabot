# Social preview font

`DMSans.ttf` is the unmodified variable DM Sans font from Google Fonts:

https://github.com/google/fonts/tree/main/ofl/dmsans

It is distributed under the SIL Open Font License in `OFL.txt`.
The server-side PNG renderer loads this bundled file directly with system font
discovery disabled. Both Docker and Vercel deployments include the same font.
